# 디자인 설명

화면 원본은 같은 폴더의 `admin.css`(관리자) · `green.css`(공개 홈페이지) · `admin.js` · `green.js`예요.
색과 글꼴 값은 맨 아래 표와 `tokens.json`에 정리했어요. 다른 사이트에서는 **구조와 부품 규칙**을 가져가고 색 · 글꼴은 새로 정하면 돼요.

## 관리자 화면

### 전체 틀 (`views/admin/layout.php`)

- 왼쪽 **사이드바**(가게 이름 + "관리자" 표시 + 메뉴) / 오른쪽 **본문**(`.admin-main`).
- 메뉴는 두 묶음이고 색으로 구분해요.
  - **업무**(녹색 `--work`): 견적 문의 · 정기청소 정산 · 일회성 정산 · 인력 배치. 처리할 일이 있으면 숫자 배지(`.nav-badge`).
  - **홈페이지 관리**(주황색 `--site`): 홈페이지 관리 · 사진 · 블로그 · 검색어 페이지 · 검색 등록 · 유입 경로 · 용량 · 후기 · 헤드 코드 · 틀 내보내기 · 계정.
- 지금 화면은 `aria-current="page"`로 표시해요.
- **휴대폰(860px 이하):** 사이드바가 위로 올라가 메뉴가 4칸 격자(아이콘 + 짧은 이름)가 돼요. CSS 파일이 늦게 와도 깨지지 않게 핵심 틀은 레이아웃 안 `<style>`에도 넣었어요.
- 맨 위에 "본문 바로가기"(`.skip-link`), 화면 읽기용 숨은 글자는 `.sr-only`.

### 한 화면의 기본 모양

```
.page-head            제목(h1) + 한 줄 설명(.muted)  |  오른쪽 버튼(.head-actions)
.tabs                 같은 영역의 하위 화면 탭(예: 블로그 › 글 목록 · 자동 글쓰기 · 경험 노트 · 사진 창고)
.notice-box / .alert  안내(연한 배경) / 오류(빨강)
.card                 내용 묶음 상자. .card.flush 는 안쪽 여백 없이 표를 꽉 채울 때
  .card-head / .card-intro   상자 머리(제목 h2 + 설명)
  .table-wrap > .table       표. 숫자 칸은 .num, 줄바꿈 막기 .nowrap, 버튼 칸 .actions
.empty-card           내용이 없을 때 안내 + 첫 행동 버튼
```

### 부품

| 부품 | 클래스 | 쓰는 곳 |
| --- | --- | --- |
| 버튼 | `.btn` + `.btn-primary`(주 행동) / `.btn-outline`(보조) / `.btn-ghost`(약한) / `.btn-danger`(지우기), 작게 `.btn-sm` | 모든 화면 |
| 상태 알약 | `.status` + `.status-paid`(완료 · 공개, 녹색) / `.status-pending`(대기 · 예약, 노랑) | 문의 상태, 정산 상태, 글 상태 |
| 입력 칸 | `.field` > label + input + `.field-help`(설명), 필수 표시 `.req` | 모든 폼 |
| 선택 버튼 묶음 | `.segmented`(라디오를 버튼처럼) | 공개/임시저장, 방식 고르기 |
| 체크 줄 | `.check-row` | 켜기/끄기 |
| 폼 배치 | `.form-grid` = `.form-main`(왼쪽 본문) + `.form-side`(오른쪽 설정 카드들) | 글쓰기, 계약 만들기 |
| 숫자 카드 | `.stat` > `.stat-value` + `.stat-label` | 통계, 정산 요약 |
| 정산 카드 | `.settle-card` | 이달 정산 |
| 작은 글 | `.sub`(회색 작은 글), `.muted`, `.warn-text`(주의), `.ok-text`(통과) | 어디나 |
| 숫자 | `.mono`(자릿수 맞춤) | 금액 · 개수 |

### 동작 규칙

- 지우기처럼 되돌릴 수 없는 버튼은 폼에 `data-confirm="…"`을 달아 한 번 더 물어요(`admin.js`).
- 저장 · 처리 뒤에는 같은 화면으로 돌아가 위에 **알림 띠**(flash)를 보여 줘요. "무엇을 했는지 + 다음에 무엇이 일어나는지"를 한 문장으로.
- 모든 POST 폼에는 `csrf_field()`가 들어가요.
- 글은 쉬운 한국어 존댓말, 전문 용어 대신 풀어 쓴 말(예: "도급 몫(대표 · 운영 수익)")을 써요.

## 공개 홈페이지 (`green.css` · `views/cleaning/`)

- 기준 폭 데스크톱 1280, 휴대폰 390 시안. 여백 변수 `--pad`(64 → 40 → 20), 구역 간격 `--section`(96 → 80 → 44).
- 머리글: 로고(이름 두 색) · 메뉴 · **무료 견적 문의** 버튼 · 전화 버튼. 휴대폰에서는 아래쪽에 전화 · 문의 버튼이 고정돼요.
- 첫 화면 구역 순서: 소개(hero) → 서비스 3가지 → 현장 사진 · 전후 사진 → 후기 → 서비스 지역 → 견적 문의 칸(`_quote_card.php`) → 바닥글(사업자 정보).
- 블로그: 카드 목록(`_post_cards.php`), 글 화면은 접히는 목차 · 조회수 · 글 아래 견적 문의 칸. 본문 글자 크기 단계 `.fs-sm` `.fs-lg` `.fs-xl`, 강조 색 두 가지(핵심 초록 · 주의 주황).
- 검색에 잘 나오게: 화면마다 제목 · 설명 · 대표 주소(canonical) · 구조화 데이터(LocalBusiness · WebSite · BlogPosting) · 사이트맵 · RSS.
- 채팅 상담(채널톡) 버튼, 카카오톡 버튼 색(`--kakao`)이 따로 있어요.
