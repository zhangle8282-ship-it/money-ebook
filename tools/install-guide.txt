전자책 스토어 설치 방법 (버전 @@VERSION@@)
================================================

  설치 코드:  @@INSTALL_CODE@@

  (설치 도구에 넣는 코드예요. 이 파일을 다른 사람에게 보여 주지 마세요.)


■ 들어 있는 파일

  install.php                 설치 도구 (서버에 이 파일 하나만 올려요)
  ebook-store-@@VERSION@@.zip        설치 파일 (설치 도구 화면에서 올려요. 압축을 풀지 마세요)
  설치방법.txt                 이 파일


■ 준비물

  - 카페24 웹호스팅 (PHP 7.3 이상, 기본 설정이면 됩니다)
  - FTP 프로그램: FileZilla (무료, https://filezilla-project.org)
  - 카페24 FTP 접속 정보: 카페24 로그인 → 나의 서비스 관리 → 호스팅 관리에서
    FTP 주소(호스트), 아이디, 비밀번호를 확인합니다. 포트는 보통 21입니다.


■ 설치하기 (처음 한 번)

  1) FileZilla로 FTP에 접속해 install.php 파일 하나만 서버의 www 폴더 안에 올립니다.
     (왼쪽 창에서 install.php 를 오른쪽 창의 www 폴더 안으로 끌어다 놓기)

  2) 브라우저에서 https://내도메인/install.php 를 엽니다.
     서버 점검 항목이 모두 "통과"인지 확인합니다.

  3) 화면에 아래 정보를 넣습니다.
     - 설치 코드: 이 파일 맨 위의 코드
     - 스토어 이름
     - 관리자 아이디와 비밀번호 (10자 이상)
     - 입금 계좌 (선택, 나중에 넣어도 돼요)
     - 설치 파일: ebook-store-@@VERSION@@.zip (압축을 풀지 않은 그대로)

  4) [설치하기]를 누르면 끝입니다.
     - 관리자로 자동 로그인되고, install.php 는 스스로 지워집니다.
     - "install.php 를 지우지 못했어요"라고 나오면 FTP로 www 폴더의 install.php 를 지워 주세요.

  5) 관리자 → 설정에서 입금 계좌와 사업자 정보를 넣고,
     관리자 → 전자책 관리 → 새 전자책 등록에서 책을 올리면 판매를 시작할 수 있어요.


■ 새 버전으로 바꾸기 (업데이트)

  관리자 → 설정 → 프로그램 업데이트에서 새 버전 zip 파일을 올리면 자동으로 바뀝니다.
  책·주문·회원 데이터와 표지는 그대로 유지돼요.
  이전 프로그램은 서버의 app.bak-날짜 폴더에 보관돼요(최근 2개).


■ 설치 도구를 쓸 수 없을 때 (FTP로 직접 설치)

  1) ebook-store-@@VERSION@@.zip 의 압축을 풀면 www 폴더와 app 폴더가 나옵니다.
  2) app 폴더를 서버의 최상위 폴더(www 폴더가 보이는 곳)에 통째로 올립니다.
     → 서버에 app 폴더와 www 폴더가 나란히 있어야 합니다.
  3) 압축을 푼 www 폴더 "안의" 파일을 모두 선택해 서버의 www 폴더 안에 올립니다.
     .htaccess 파일도 꼭 함께 올라가야 합니다(점으로 시작해 Finder에서는 안 보일 수 있어요).
     서버 www 폴더에 예전 index.html 이 있으면 지워 주세요.
  4) https://내도메인/health 에서 "ok":true 가 보이면 성공입니다.
  5) https://내도메인/admin 에 들어가 관리자 계정을 바로 만드세요.


■ 꼭 지켜 주세요

  서버의 아래 두 폴더는 지우지 마세요. 판매 데이터가 들어 있어요.
    - storage 폴더 (최상위, www 옆): 회원·주문·리뷰·설정 DB, 전자책 원본
    - www/uploads 폴더: 표지 이미지, PDF 미리보기 이미지

  다른 계정·호스팅으로 옮길 때는 새 서버에 설치한 뒤, 예전 서버의 위 두 폴더를
  내려받아 새 서버의 같은 위치에 올리면 데이터가 그대로 옮겨집니다.


■ 관리자 비밀번호를 잊었을 때

  1) 내용이 없는 빈 파일을 만들어 이름을 reset-admin 으로 저장합니다(확장자 없이).
  2) FTP로 서버의 storage 폴더 안에 올립니다.
  3) https://내도메인/admin 에 들어가면 관리자 계정 만들기 화면이 다시 나와요.
     책·주문·회원 데이터는 그대로 남아 있어요.


■ 문제가 생길 때

  - 책을 누르면 "Not Found" 가 나옴 → www 폴더에 .htaccess 가 없습니다.
    설치 도구로 다시 설치하거나 FTP로 .htaccess 를 올려 주세요.
  - "잠시 문제가 생겼어요" 가 나옴 → https://내도메인/health 에서 false 인 항목을 확인하세요.
  - "이미 설치된 사이트예요" 가 나옴 → 관리자 계정이 있는 사이트예요.
    새 버전은 관리자 → 설정 → 프로그램 업데이트에서 올려 주세요.
  - 큰 전자책 파일이 안 올라감 → 호스팅 업로드 용량 한도 때문이에요.
    카페24 고객센터에 한도를 늘릴 수 있는지 문의해 주세요.
